# Italiano — iPhone용 PWA

이 폴더는 Italiano를 iPhone 홈 화면에서 앱처럼 설치해 사용하는 배포용 파일입니다.

## 설치
1. 이 폴더 전체를 HTTPS로 제공되는 정적 웹 호스팅에 업로드합니다.
2. iPhone Safari에서 사이트 주소를 엽니다.
3. 공유 버튼 → 홈 화면에 추가 → 추가를 누릅니다.
4. 홈 화면의 Italiano 아이콘으로 실행합니다.

## 중요
- 반드시 HTTPS 환경에서 사용하세요.
- 학습 데이터는 브라우저의 로컬 저장소/IndexedDB에 저장됩니다.
- 브라우저 데이터 삭제나 사이트 데이터 초기화 전에는 앱의 백업 기능을 사용하는 것을 권장합니다.
- 이 패키지는 현재 Italiano의 기능을 유지하고 iPhone 설치에 필요한 PWA 파일을 정리한 것입니다.
